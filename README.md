# BRASIL: PRESIDENTE

Simulador político e de administração pública. O jogador disputa a eleição presidencial de 2026, governa o Brasil de 2027 a 2030 e responde pelas consequências.

É uma história alternativa: políticos reais aparecem em um cenário hipotético, e ações, pesquisas e resultados são inventados pelo jogo.

**Jogue agora:** https://paulosantiagooh.github.io/brasil-presidente/

## Estado atual

Etapas 1 a 6 do plano: criação do candidato, campanha de cinco semanas, eleição em dois turnos, formação do governo e um mandato jogável de 48 meses, com medidas escritas pelo jogador, negociação e votação no Congresso, economia, orçamento, sociedade, segurança, obras, estatais, instituições, diplomacia, eventos, relatórios e balanço final. O gabinete fictício traz dilemas e histórias em capítulos, com crises urgentes, manchetes, redes sociais, missões, conquistas e nota final. Há reeleição em 2030, segundo mandato até 2034, impeachment, reforma ministerial, Congresso em 3D e a opção de jogar com um político real. O jogo pode ser instalado pelo navegador, e as partidas podem ser exportadas e importadas. Faltam contas com sincronização automática e os aplicativos nas lojas.

O documento completo do projeto está em [docs/PROJETO.md](docs/PROJETO.md).

## Rodar no computador

```bash
npm install
npm run dev
```

O jogo abre em `http://localhost:3100`.

## Conferir antes de salvar

```bash
npm run typecheck
npm run build
```
