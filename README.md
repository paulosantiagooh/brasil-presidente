# BRASIL: PRESIDENTE

Simulador político e de administração pública. O jogador disputa a eleição presidencial de 2030, governa o Brasil por quatro anos e responde pelas consequências.

O cenário é uma simulação: o jogo não presume candidatos nem resultados reais de 2030.

## Estado atual

Etapas 1 a 3 do plano: tela inicial navegável, partidas salvas no aparelho, configurações, criação completa do candidato e campanha de cinco semanas, com agenda, mapa dos 27 estados, pesquisas, debates, entrevistas e boletins. Tudo funciona no computador e no celular. A próxima etapa é a eleição.

O documento completo do projeto está em [docs/PROJETO.md](docs/PROJETO.md).

## Rodar no computador

```bash
npm install
npm run dev
```

O jogo abre em `http://localhost:3100`.

## Conferir antes de salvar

```bash
npm run typecheck
npm run build
```
